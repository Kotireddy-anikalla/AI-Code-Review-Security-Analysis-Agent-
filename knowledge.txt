SQL Injection:
Use parameterized queries (prepared statements) with placeholders.
Never concatenate user input directly into SQL strings.
Example (Python): cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))
Example (Java): PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users WHERE id = ?"); stmt.setString(1, userId);

Cross-Site Scripting (XSS):
Escape all user-generated content before rendering in HTML.
Use frameworks like React that auto-escape by default.
For manual escaping, use html.escape() in Python, or OWASP Java Encoder.
Context matters: escape for HTML, JavaScript, CSS, URL separately.

Hardcoded Secrets:
Never store passwords, API keys, or tokens in source code.
Use environment variables: os.getenv('API_KEY').
Use secret management services (AWS Secrets Manager, HashiCorp Vault).
Rotate secrets regularly and use different secrets for different environments.

Authentication & Password Management:
Use strong password hashing algorithms: bcrypt, Argon2, PBKDF2.
Always use a salt for password hashing.
Enforce multi-factor authentication (MFA) for sensitive actions.
Implement account lockout after failed attempts (e.g., 5 failures).
Use secure, HttpOnly, SameSite cookies for session tokens.

Access Control (Authorization):
Always check permissions on the server side.
Follow the principle of least privilege.
Deny by default; allow explicitly.
Use role-based access control (RBAC) or attribute-based access control (ABAC).

Insecure Deserialization:
Avoid deserializing untrusted data.
Use safe serialization formats like JSON with schema validation.
Implement integrity checks (digital signatures) on serialized objects.

Security Misconfiguration:
Disable default accounts and passwords.
Set secure HTTP headers: HSTS, X-Frame-Options, X-Content-Type-Options.
Run services with least privilege and in non-root containers.
Keep all software (libraries, frameworks) up to date.

Sensitive Data Exposure:
Encrypt sensitive data at rest (AES-256) and in transit (TLS 1.2+).
Use strong key management and never hardcode keys.
Mask sensitive data in logs and error messages.
Store only hashed versions of passwords, credit card numbers, etc.

XML External Entities (XXE):
Disable external entity processing in XML parsers.
Use secure parsing libraries that are not vulnerable to XXE.
Prefer JSON over XML where possible.

Broken Access Control:
Use server-side access control checks for every request.
Implement proper session management; invalidate sessions on logout.
Use anti-CSRF tokens for state-changing operations.

Logging & Monitoring:
Log all access control failures, authentication events, and errors.
Protect log integrity (append-only, secure storage).
Monitor logs for suspicious patterns and alert on anomalies.

Cryptography:
Use well-known libraries (e.g., cryptography, Bouncy Castle).
Never implement your own crypto algorithms.
Use secure random number generators (e.g., secrets module in Python).

File Upload:
Validate file type (allowlist extensions and MIME types).
Scan uploaded files for malware.
Store uploaded files outside the webroot.
Rename files to avoid path traversal attacks.

Error Handling:
Return generic error messages to users (e.g., "Invalid credentials").
Log detailed errors internally for debugging.
Avoid exposing stack traces or database details in responses.

Session Fixation:
Regenerate session IDs after successful authentication.
Use session tokens with sufficient entropy and expiration.

API Security:
Use API keys or OAuth2 for authentication.
Implement rate limiting to prevent brute force.
Validate all input parameters using strict schemas.
